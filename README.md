# 75專用角色卡備份小幫手

> 作者：懶人阿暝

一個打開就能用的網頁小工具。它可以把 AI 角色卡按欄位整理好，匯出前先幫你檢查，再一鍵打包成 zip 備份。

免安裝，也不需要註冊，只要下載一個 html 檔，用瀏覽器打開就好。

---

## 功能

- **照分頁逐格填寫**：個人資料 → 基本設定 → 首場 → 故事 → 詳細設定 → 事件，順序和角色卡一樣
- **每一格都能單獨複製**，方便貼回角色卡
- **性別用選的**：男／女／未設置（選未設置時不會輸出這一欄）
- **故事**：解鎖故事時的提示語、故事標題、內容，檔名會跟著標題自動變成 `故事-1-標題.txt`
- **事件**：時間和地點、標題、內容，檔名一樣自動變成 `事件-1-標題.txt`
- **共用範本**：常用的事件可以存成範本，其他角色直接從選單加入
- **附加資訊 10 格**：每格分成「標題」和「內容」
- **草稿整理**：貼上整段草稿，選取文字後就能放進指定欄位
- **檢查**：會列出必填欄位空白、故事缺少標題或內容、殘留其他角色名字這幾類問題
- **輸出預覽**：可以先看匯出後每個 txt 的實際內容
- **匯入／匯出**：支援 zip 和 txt，可以只匯出一張，也可以整個角色庫一起匯出

## 使用方式

1. 下載 `75專用角色卡備份小幫手.html`
2. 用瀏覽器打開，Chrome、Edge、Safari、Firefox 都可以
3. 按「＋ 新增角色」開始填寫，或按「匯入 zip／txt」讀入之前的備份
4. 整理完之後，按「匯出這張 (.zip)」或「全部匯出」

## ⚠️ 資料與隱私

- 所有資料都**只存在你自己的瀏覽器裡**，不會上傳到任何伺服器
- 清除瀏覽器資料、換瀏覽器或換裝置，資料都會不見
- **整理完請一定要匯出 zip 備份**
